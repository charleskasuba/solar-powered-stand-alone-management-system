# solar-powered-stand-alone-management-system

Real-time solar microgrid monitoring and energy management dashboard for Copperbelt University, Kitwe, Zambia.

## Features

- Real-time battery, inverter, and load monitoring via ESP32 sensors
- Historical power trends and energy predictions
- Weather integration (Open-Meteo API)
- Energy-saving recommendations
- Flask-based web dashboard with Chart.js and Plotly.js

## Tech Stack

- **Hardware:** ESP32, PZEM004Tv30, INA219, relays, 20x4 LCD
- **Backend:** Python, Flask
- **Frontend:** HTML, Chart.js, Plotly.js
- **Deployment:** Render
